**Goal:** Implement the supplied admin workspace using existing APIs and session permissions.
**Spec:** [Admin UI design](../specs/2026-10-12-admin-ui-design.md)

## Review focus

- Stale responses must not replace a newly selected user/report or filter result.
- Pending mutations must not be double-submitted or discarded by closing a dialog.
- Moderation actions and report resolution are separate writes: never repeat a completed sanction on retry.
- Autosave must serialize writes, preserve rejected edits, and never claim invalid or unsaved values are saved.
- CSV export must preserve filters, cover every page, escape dangerous cell prefixes, and fail as a whole.
